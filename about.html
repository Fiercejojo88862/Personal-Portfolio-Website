My story

I didn't start with a computer science classroom. I started with a love of cars. I'm an enthusiast first: I follow the engineering, keep my 2011 Mercedes GL450 meticulously maintained, and track everything in my self-hosted garage app. That obsession with how machines work carried straight into code and Linux systems.

When I got into self-hosting, there was no tutorial for my exact setup, so I learned Docker networking, permissions, and indexer APIs the hands-on way, one broken container at a time. That homelab is still running today, and it taught me more about real systems than any single class.

In 2026 I entered Software and Data Engineering Technology (major approved that June after an appeal) and started bending my Linux desktop itself into shape, building a Python web customizer for the Omarchy lock screen. This portfolio is the next step: hand-written HTML, CSS, and JavaScript, deployed to GitHub Pages and NJIT's student server.

Principles I build by

🔍 Diagnose before fixing

From a finicky SUV suspension to broken containers: research first, reproduce the issue, then change one thing at a time.

🏠 Self-host first

If a service can run on my own hardware, it should. Private, free, and fully under my control.

📝 Leave notes behind

Every project gets a README and a gotcha list, including the stale-server bug that once broke my lock screen.
