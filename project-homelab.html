Docker Media Homelab

Self-hosted media stack on Arch Linux. Built 2024. Sole builder and operator.

  • Docker Compose
  • Linux
  • Networking

What it does

Five services running as containers: Jellyfin for streaming, Radarr for library management, qBittorrent for downloads, Prowlarr for indexer management, and LubeLogger for the garage. A private alternative to paid streaming, running on my own hardware.

Hardest problem

Containers could not see each other's volumes until user and group IDs were mapped correctly, and the indexer needed its API key re-issued. Lesson: check identity and credentials before blaming the network.

Outcome

A stack that has run since 2024 and taught me real systems administration: permissions, networking, secrets, and recovery.
