omarchy-lock-studio

Python web customizer for the Omarchy lock screen. Built 2026. Sole builder.

  • Python
  • QML
  • HTML/CSS/JS
  • Linux

What it does

A local web app (served on port 8731) that customizes the Omarchy lock screen: clock, profile with editable welcome line, dev quotes, MPRIS media display, background picker with automatic upscaling, theme and custom text colors, plus backup and restore. It generates LockView.qml while preserving the password field and PAM authentication.

Hardest problem

A stale dev server once re-wrote a broken LockView.qml and killed the lock screen. The fix became process: relaunch the app (it takes over port 8731) before clicking Apply, and back up on every write.

Outcome

My daily-driver lock screen, themed end to end, with a safety net that makes experimenting free.
