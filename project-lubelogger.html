LubeLogger: Vehicle Maintenance

Self-hosted garage tracker in my Docker homelab. Sole operator.

  • Self-hosted
  • Docker
  • HTML/CSS

What it is

LubeLogger is a self-hosted vehicle maintenance app: it logs fuel-ups, services, and repairs, tracks costs across every vehicle in the garage, and sends maintenance reminders. No subscriptions, no cloud account, private by design.

Why I run it

As a car enthusiast keeping a high-mileage SUV on the road, honest records matter: every fuel-up and repair dated, so cost-per-mile stays accurate and nothing gets forgotten.

Outcome

One garage view for the whole fleet, deployed next to the media stack in minutes using the Docker skills from the homelab build.
